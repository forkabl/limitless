# Why are browsers boring?

I hate boring browsers. Here are features I would like to have:
1. Vertical tabs
2. Shortcuts familiar from tmux or Herdr
3. Retain features from Chrome: Chrome extensions
4. Privileged extensions: adding support for uBlock Origin and pre-bundling
5. Sharp UI; rounded UI in Chrome is ugly and eats a lot of space
6. Every setting should be CLI-able and updatable by agents
7. Fuzzy search through tabs and history
8. Command+Z to reopen closed tabs
9. No Google password manager
10. Split panes as easy to use as Herdr
11. Herdr for browsers
12. AI-compatible but not in-your-face AI
13. Peeking into a link
14. Spotlight-style command palette
15. Gradient themes
